; ── Threading: reorders work, and the deterministic path is single-threaded ─
; ONE EXEMPTION: Fracture/SimJobs.cs disables RS0030 for the whole file. It is the

; thread count — fixed chunk count, chunks writing only their own items, cross-chunk
; accumulators merged in chunk order. Results are bit-identical on 1 worker and on
; 12, and identical to running sequentially, which the simulation fingerprint checks
; directly. Nothing else in the project may touch these types; the ban below is what
; keeps that true. See PORT_PLAN.md §6 rule 8.
